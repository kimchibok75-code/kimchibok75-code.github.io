# 치복 타운 그림 폴더

지금 게임 그림은 모두 코드(game.html)로 그린 것이에요. 이 폴더의 PNG는 그 그림을 그대로 뽑아 둔 **참고용 사본**이에요.
(2026-11-16에 뽑음. 게임은 아직 이 파일들을 읽지 않음)

직접 그린 그림으로 바꾸고 싶으면, 같은 이름으로 덮어쓰거나 새 파일을 넣은 뒤 Claude에게 "○○를 이 그림으로 바꿔 줘"라고 하면 돼요.
- 형식: 배경이 투명한 PNG
- 크기: 화면에서 보이는 크기의 2배쯤 (지도 1칸 = 32px → 64px로 그리기)

| 폴더 | 들어 있는 것 |
|---|---|
| `char/` | 캐릭터 기본 · 헤어(`hair/`, 색은 `hair-color/`) · 모자(`hat/`) · 눈(`eyes/`) · 의상(`suit/`) · 무기 스킨(`weapon-skin/`) · 장비 단계별 모습(`gear/`) |
| `item/` | 장비 아이콘: 칸별 1~6단계(`sword/ bow/ staff/ hat/ armor/ shoes/`), 등급별 보석 색(`grade/`) |
| `mon/` | 사냥터 몬스터 · 보스(`boss-…`) · 레이드 드래곤 |
| `build/` | 건물(카페·가챠센터·마을회관 등) · 집 단계(`house-lv0~5`) · 지붕 색(`house-roof1~8`) |
| `nature/` | 나무(`tree-…`) · 캘 수 있는 나무·바위(`gather-…`) · 작물(`crop/`) |
| `props/` | 분수 · 벤치 · 낚시터 표지판 · 사냥터 포탈 |
| `ui/` | 화면 아이콘 (이모지 대신 쓰는 그림) |
| `bg/` | 바닥 전체 그림: 마을(`town.png`) · 사냥터 4곳 · 레이드 |

다시 뽑는 방법은 `scripts/img-export/` 참고 (CLAUDE.md에 적어 둠).
