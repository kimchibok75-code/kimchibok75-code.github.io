[0. 적용 범위 및 확정 사항]
- 수역: 민물, 바다. 서로 독립된 등장 확률표를 사용한다.
- 물고기 및 기타 포획물: 민물 32종(일반15 / 희귀10 / 전설7), 바다 37종(일반17 / 희귀14 / 전설6), 합계 69종.
- 낚싯대 10단계와 미끼 10단계. 두 장비 모두 영구 업그레이드이며 소모되거나 내구도가 감소하지 않는다.
- 가장 저렴한 기본 판매가: 2원. 일반은 대체로 50원 전후, 희귀는 대체로 1,000원 전후.
- 전설의 기본 판매가는 최소 10,000원. 전설의 실제 판매가는 10,000원 이상, 모든 포획물의 실제 판매가는 10,000,000원 이하로 제한한다.
- 사용자의 '최대 10000000만원' 요청은 앞선 합의대로 게임 내 1,000만원(10,000,000원) 상한으로 해석한다.
- 전설의 최소 포획 크기와 최대 크기는 현실을 벗어나는 판타지 설정. 실존 생물 크기는 게임용 단순화 범위.
- 어종별 수치 전체는 엑셀 '물고기 69종' 및 '전설 해금조건' 시트를 단일 데이터 원본으로 사용한다.

[1. 낚싯대와 미끼 역할]
낚싯대: (1) 낚시 시도 성공률 (2) 포획할 수 있는 개체의 최대 길이 (3) 전설별 최소 요구 단계.
미끼: 일반/희귀/전설 중 어떤 등급을 만날지 결정하는 확률. 미끼는 영구 장착으로 간주하며 사용 횟수 제한이 없다.
두 장비는 원하는 순서로 독립 업그레이드할 수 있다. 예: 낚싯대 Lv8 + 미끼 Lv5.

[6. 물고기 등장 확률 정의]
- 엑셀 '물고기 69종'의 개별 등장 확률은 미끼 Lv10, 해당 수역에서 '낚시 성공 후'의 확률이다.
- 민물과 바다의 등급 합계: 일반 88%, 희귀 11%, 전설 1%.
- 다른 미끼 단계에서는 등급별 비율을 해당 미끼 행의 값으로 교체한다.
- 등급 내부 어종 가중치는 엑셀의 최종 미끼 개별 확률값을 등급 내 합계로 나눈 값으로 고정한다.
- 예: 민물 Lv10 전설 내부에서 김치 잉어 비중 = 0.30 / 1.00 = 30%.
- 예: 바다 Lv10 전설 내부에서 수정 리바이어던 비중 = 0.003 / 1.000 = 0.3%.
- 전설에 적용된 최종 수정 확률(해당 수역 내 낚시 성공 기준):
  바다 황금 참치 0.42%, 망령 해파리 0.28%, 메카 심해어 0.18%,
  기계 상어 0.107%, 은하 고래 0.010%, 수정 리바이어던 0.003%. 합계 1%.
- 민물 전설은 기존 개별 확률 유지. 엑셀 참조.
- 일반·희귀의 개별 확률도 모두 엑셀 원본 값 유지.
- 특정 등급의 포획 가능 어종이 하나도 없다면 그 등급의 확률을 다른 유효 등급에 비례해 재분배한다.
- 특정 등급 내에서 포획 불가능한 물고기는 후보 목록에서 제외하며 나머지 물고기의 가중치를 다시 100%로 정규화한다.
  이는 크기를 먼저 결정해 실패 처리하는 방식과 다르며, '낚싯대가 낚을 수 있는 물고기만 등장'하도록 구현한다.
- 따라서 원본 개별 확률은 '낚싯대 Lv10 + 미끼 Lv10'에서만 최종 발생 확률과 정확히 일치한다.

[7. 포획 알고리즘 — 정확한 순서]
1) 플레이어가 민물/바다 낚시터 선택.
2) 낚싯대 Lv의 성공률로 낚시 성공 여부를 추첨; 실패하면 포획물 없고 판매가 0원.
3) 해당 수역의 모든 포획물 중 다음 조건을 만족하는 후보만 생성:
   a. 해당 물고기의 최소 길이 <= 현재 낚싯대 최대 포획 길이
   b. 낚싯대 Lv >= 해당 물고기의 최소 요구 낚싯대 Lv
   c. 미끼 Lv에서 해당 물고기 등급의 기본 확률이 0이면 제외
4) 유효 후보가 1종 이상 있는 각 등급에 대해 미끼의 등급 확률을 추출하고, 유효 등급 간 총합 100%로 정규화.
5) 정규화된 확률로 등급 선택.
6) 해당 등급의 유효 물고기들 중 엑셀 개별 확률 가중치로 어종 추첨(가중치 재정규화).
7) 물고기 크기는 [기본 최소 크기, MIN(기본 최대 크기, 낚싯대 최대 포획 크기)] 구간에서 균등 추첨.
8) 크기로 판매가 배율을 계산. 최종 판매가는 원 단위 반올림하고 10,000,000원 상한 적용.
9) 포획 결과, 낚시 기록, 재화 지급 처리.
※ 3~6단계는 성능을 위해 캐시된 후보·누적가중치 테이블로 구현할 수 있다.
※ 각 낚시 시도는 서로 독립이며 천장(보장 횟수) 없음. 이는 별도 규칙으로 추가하기 전의 기본 설계.

[8. 크기·판매 가격 공식]
- 기본 최소 크기 MIN_SIZE, 기본 최대 크기 MAX_SIZE, 실제 포획 크기 FISH_SIZE.
- 크기 백분위 SIZE_RATIO = (FISH_SIZE - MIN_SIZE) / (MAX_SIZE - MIN_SIZE).
- 크기 계수 MULTIPLIER = 0.5 + SIZE_RATIO.
- 판매가 SELL_PRICE = MIN(10,000,000, MAX(전설이면 10,000 / 아니면 0, ROUND(BASE_PRICE * MULTIPLIER))).
- 최소 크기 = 기본가의 0.5배, 중간 크기 = 기본가의 1.0배, 최대 크기 = 기본가의 1.5배.
- 포획 가능 크기를 낚싯대가 제한해도 비율 계산의 분모 MAX_SIZE는 원래 어종 범위의 최대치다.
- 일부 전설(특히 수정 리바이어던)은 크기 계수가 1.0 이상일 때 가격 상한으로 인해 실제 가격 증가가 멈춘다.
- 정수 가격은 원 단위 반올림(정확한 0.5는 올림)을 사용한다.
- 전설은 크기 보정 후에도 실제 판매가 최소 10,000원을 보장한다. 전설의 기본 판매가도 최소 10,000원이다.
- 참게/꽃게는 갑각 너비, 자라는 등딱지 길이, 가오리는 몸통 폭, 소라/다슬기는 껍데기 길이,
  문어/대왕문어/대왕오징어는 다리 포함 길이 등 어종별 측정 기준 적용(엑셀 참조).

[9. 업그레이드 구매 처리]
- 플레이어는 낚싯대 Lv1 / 미끼 Lv1을 무료 지급받는다.
- 각 장비 Lv10이 최종 단계다. 1→2→...→10 순차 구매만 허용하며 단계 건너뛰기는 불가.
- 구매는 충분한 재화가 있을 때만 허용; 구매 즉시 재화를 차감하고 장비 단계 영구 저장.
- 10단계 이후에는 업그레이드 버튼을 비활성화하거나 '최대 레벨'로 표시.
- 낚싯대와 미끼 업그레이드는 서로 독립; 두 장비를 반드시 함께 올릴 필요는 없음.
- 미끼 구매나 추가 장착을 위한 별도 소비 금액은 없음.
