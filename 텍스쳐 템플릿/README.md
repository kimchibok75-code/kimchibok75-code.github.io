# 치복 타운 텍스쳐 템플릿

직접 그린 그림을 게임에 넣기 위한 틀이에요. (2026-11-17 만듦)

## 파일은 두 개씩 있어요
| 파일 | 뭐예요 |
|---|---|
| `이름.png` | **바꿀 그림.** 배경이 투명하고, 지금 게임 그림이 들어 있어요. 이 파일과 **크기·위치를 똑같이** 해서 내 그림을 저장하면 돼요 |
| `이름_guide.png` | **밑그림용 안내.** 격자 · 빨간 기준점 · 칸 표시 · 설명이 들어 있어요. 그릴 때 맨 아래 레이어로 깔고, 저장할 때는 숨기기 |

## 그리는 순서
1. 그림 프로그램에서 `이름_guide.png`를 열기 (캔버스 크기가 그대로 정해짐)
2. 그 위에 새 레이어를 만들어 그리기 (빨간 점 = 기준점, 이 점은 절대 옮기지 않기)
3. 안내 레이어를 숨기고, **배경 투명 PNG**로 저장 (캔버스 크기 그대로, 자르지 않기)
4. 저장한 파일을 이 폴더 어딘가에 넣고 Claude에게 말하기
   - 예: "텍스쳐 템플릿/char/hat.png 자리에 `내그림/밀짚모자.png` 넣었어. 밀짚모자 스킨을 이걸로 바꿔 줘"
   - 예: "카페 그림을 `텍스쳐 템플릿/building/cafe.png`로 바꿨어, 적용해 줘"

같은 틀로 여러 장을 그려도 돼요. (모자 10개 → 모자 틀로 10장, 이름만 다르게)

## 들어 있는 틀
크기는 모두 게임 화면보다 크게 그려 둔 것이라 확대해도 또렷해요.

### 캐릭터 `char/` — 384×384, 기준점 = 발 (1칸 = 128px)
| 파일 | 쓰는 곳 |
|---|---|
| `eyes` | 눈 (눈 스킨 전부). 두 눈을 한 장에 |
| `hair-back` · `hair-front` | 헤어. 뒷머리(얼굴 뒤)와 앞머리(얼굴 위) 두 장. 뒷머리가 없는 모양이면 빈 그림 |
| `hat` | 모자 (모자 스킨 + 모자 장비 1~6단계 모두) |
| `suit-back` · `suit-front` · `suit-sleeve` | 의상 (의상 스킨 + 갑옷 장비 모두). 망토·날개(몸 뒤) / 몸 / 소매. **소매는 256×256, 기준점 = 어깨** (팔이 흔들려서 따로) |
| `_base-ref` | 참고용 기본 캐릭터 (바꾸는 파일 아님) |

- 캐릭터가 왼쪽을 볼 때는 게임이 그림 전체를 좌우로 뒤집어요
- 헤어는 **흰색·회색으로** 그리면 게임이 머리 색 8가지를 입힐 수 있어요 (색까지 그리면 그 색으로 고정)

### 무기 `weapon/` — 384×544, 기준점 = 손이 쥐는 곳 (1칸 = 256px)
`sword` 검 · `bow` 활 · `staff` 지팡이. 날(끝)은 위쪽으로. 단계별(1~6)·무기 스킨별로 같은 틀에 한 장씩. 가방·가챠 아이콘도 이 그림을 돌려서 써요.

### 물고기 `fish/` — 512×512, 기준점 = 가운데
`fish` 한 장 틀. 머리는 왼쪽, 파란 점선 안에 꽉 차게. 물고기 종류마다 한 장씩.

### 몬스터 `monster/` — 360×320, 기준점 = 발 (1칸 = 128px)
`monster` 한 장 틀 (멧돼지 예시). 정면을 보게. 보스는 게임이 크게 키우고 왕관을 씌워요. 그림자는 코드가 그림.

### 건물 `building/` — 기준점 = 차지하는 칸의 왼쪽 위 (1칸 = 64px)
| 파일 | 건물 | 크기 |
|---|---|---|
| `gacha` | 가챠센터 (8×5칸) | 592×520 |
| `cafe` | 카페 (6×4칸) | 464×456 |
| `hall` | 마을회관 (6×5칸) | 464×520 |
| `smith` | 대장간 (6×5칸) | 464×520 |
| `skin` | 스킨샵 (5×4칸) | 400×456 |
| `lumber` | 벌목소 (5×4칸) | 400×456 |
| `quarry` | 채광소 (5×4칸) | 400×456 |
| `farmshed` | 텃밭 창고 (4×3칸) | 336×392 |
| `fishshop` | 낚시점 (3×3칸) | 272×392 |
| `house-lv0` ~ `house-lv5` | 집 1~6단계 (3×2칸): 일반 집 · 2층 집 · 큰 집 · 빌라 · 4층 건물 · 빌딩 | 272×228 ~ 272×528 |

- 파란 점선 = 건물이 차지하는 칸 (이 밖으로 지붕·간판이 튀어나와도 괜찮음)
- 초록 점선 = 문 앞 (캐릭터가 여기로 들어감)
- 주황 점 = 코드가 따로 그리는 것 (이름표 · 굴뚝 연기 · 커피 김 · 가챠 불빛 · 깃발). 그 자리는 비워 두거나 어울리게
- 마을 그림 스타일: 위에서 내려다본 3/4 시점, 테두리 없는 면
- 집은 지붕 색 8가지 중 1번(초록)으로 그려져 있어요. 지붕 색을 고르는 기능을 살리려면 지붕만 따로 그려야 해요 (적용할 때 말해 주세요)

## 템플릿을 다시 만들려면 (Claude용)
1. 백그라운드로 `node scripts/img-export/tpl-recv.mjs` (5199 포트, 이 폴더에 저장 + `template.js`를 내 줌)
2. game.html의 `// 화면 이동은 실제 화면 점` 줄 **앞에 새 줄로** 넣기:
   `window.__tplCtx = () => ({ drawChar, drawEyes, hairParts, hatParts, suitParts, weaponParts, inkDraw, flatInk, R, E, MON_ART, MONS, BLD, BUILDINGS, LAB, houseTop, HOUSE, HOUSE_EX, HOUSE_W, HOUSE_H, T, HAIR_COLORS });   // DEBUG-REMOVE`
3. 미리보기에서 game.html을 열고 JS로 `(await import('http://localhost:5199/template.js?t=' + Date.now())).run(window.__tplCtx())` (로그인 필요 없음)
4. DEBUG-REMOVE 줄 지우기
