## 1. 한 줄 소개

**가제: 「김치복 마을」**
머리가 큰 SD 캐릭터로 마을에서 **인생 한 판**을 살아 보는 웹 게임.
학교, 회사, 카페 같은 건물을 다니며 능력치를 키우고 돈을 법니다. 그러다 다른 팬들을 만나 대화도 해요.
인생이 끝나면 **결과(엔딩)가 기록으로 남고**, 새 인생을 다시 시작할 수 있어요.

- 주소(예정): `https://kimchibok75-code.github.io/game.html`
- 홈페이지 메뉴와 휴대폰 하단 탭에 "게임" 추가

## 2. 핵심 재미 — 무엇을 하는 게임인가

### 2-1. 인생 한 판의 흐름
```
캐릭터 만들기 → 20살 시작 → 건물에서 행동 (공부·운동·알바·취직…)
   → 나이 먹음, 이벤트 발생 → 60살 은퇴 → 인생 결과 정리 → 기록 저장 → 새 인생
```

- **나이 = 진행도.** 행동을 할 때마다 시간이 흘러요. (예: 행동 4번 = 1살)
- **한 인생 길이 목표: 실제로 약 1~2주.** 매일 조금씩 접속해서 키우는 느낌
  - 하루에 쓸 수 있는 **행동력(⚡)**이 정해져 있어요. 예: 최대 20, 1시간에 2씩 회복
  - 너무 빨리 끝나지도, 너무 오래 걸리지도 않게 숫자는 테스트하며 조절
- 엔딩 예시: "대기업 사장", "전설의 림월드 스트리머", "동네 카페 사장님", "평범하지만 행복한 인생", "빚더미 인생" …
  - 엔딩은 능력치, 돈, 직업, 행복도 조합으로 정해져요.
  - **처음 본 엔딩은 도감에 수집**돼서 다시 플레이할 이유가 생겨요.

### 2-2. 캐릭터 능력치
| 능력치 | 올리는 곳 | 쓰이는 곳 |
|---|---|---|
| 💪 체력 | 헬스장, 공원 산책 | 힘든 알바, 병 예방 |
| 🧠 지능 | 학교, 도서관 | 좋은 직업, 승진 |
| ✨ 매력 | 옷가게, 미용실, 광장에서 대화 | 인기, 연애·친구 이벤트 |
| 😊 행복 | 카페, 집에서 쉬기, 친구 만나기 | 엔딩 점수, 낮으면 번아웃 |
| 💰 돈 | 알바, 회사, 은행 이자 | 아이템, 집 업그레이드 |

### 2-3. 지도에 있는 건물 (1차 후보)
| 건물 | 하는 일 |
|---|---|
| 🏠 내 집 | 쉬기(행복·행동력 회복), 꾸미기 |
| 🏫 학교 / 📚 도서관 | 지능 올리기, 자격증 |
| 🏋️ 헬스장 | 체력 올리기 |
| ☕ 카페 | 알바(돈), 쉬기(행복), 다른 유저와 대화 명소 |
| 🏢 회사 | 취직, 출근(돈), 승진 |
| 🏦 은행 | 저축(이자), 대출(위험!) |
| 🏥 병원 | 아플 때 회복 |
| 👕 옷가게 / 💇 미용실 | SD 캐릭터 꾸미기 (매력↑) |
| 📺 방송국 | **김치복 테마** — 스트리머 직업, 인기 올리기 |
| ⛲ 광장 | 다른 유저가 제일 많이 모이는 곳, 채팅 |
| 🌲 개척지 (마을 밖) | 랜덤 모험 이벤트 — 좋은 일·나쁜 일 (림월드 느낌의 사건들) |

> 림월드 느낌은 **분위기와 이벤트 문장**으로만 살려요. 림월드 게임 그림이나 이름은 쓰지 않아요(저작권).

### 2-4. 랜덤 이벤트
- 행동할 때 가끔 이벤트 카드가 떠요. 예: "길에서 지갑을 주웠다 → 주인 찾아주기 / 갖기"
- 선택에 따라 능력치, 돈, 행복이 바뀌어요. 인생마다 다른 이야기가 나오게 만드는 핵심이에요.

### 2-5. 김치복 방송과 연결 (홈페이지만의 특별함)
- **김치복이 치지직 방송 중이면 마을에 이벤트가 열려요.** 예: 광장 전광판 켜짐, 그 시간 행동력 2배
  - 이미 만들어 둔 생방송 감지(Cloudflare Worker)를 그대로 활용
- 김치복 본인 캐릭터가 마을에 NPC로 등장하는 것도 가능 (선택)

## 4. SD 캐릭터 (머리 큰 캐릭터)

- **머리 : 몸 = 약 1 : 1** 비율의 귀여운 SD 스타일
- **부품 조합 방식**으로 그려요. 부품을 겹쳐서 한 캐릭터를 만듭니다.
  - 순서: 몸 → 옷 → 머리(얼굴형) → 눈 → 입 → 머리카락 → 모자/장식
  - 부품을 바꾸면 꾸미기가 되고, 옷가게에서 산 아이템이 부품으로 추가돼요.
- 그림 형식: **SVG(벡터 그림)**. 휴대폰에서도 선명하고 파일이 작아요.
- 표정 변화: 행복도에 따라 웃는 얼굴 / 지친 얼굴
- 걷는 모습: 몸이 살짝 통통 튀는 간단한 애니메이션
- **그림을 누가 그릴지 정해야 해요** → 맨 아래 "정해야 할 것" 참고

## 5. 로그인과 저장

### 5-1. 로그인 (간단하게)
- **추천: 닉네임 + 비밀번호**로 가입 (이메일 없이)
  - 비밀번호는 서버에 그대로 저장하지 않고 **암호화(해시)**해서 보관해요.
  - 로그인하면 휴대폰/PC에 "로그인 유지" 표시를 저장해서 매번 입력하지 않아도 돼요.
- 다른 방법: **디스코드로 로그인** — 김치복 디스코드 서버 멤버라면 버튼 한 번으로 가입 (나중에 추가 가능)
- 비밀번호를 잊으면 복구가 어려워요. 그래서 처음 가입할 때 **"복구 코드"**를 한 번 보여 주고 적어 두게 할게요.

### 5-2. 저장 — "결과를 매번 잘 저장"
- **행동 한 번 할 때마다 서버에 바로 저장**해요. 저장 버튼이 따로 없어요.
  - 창을 닫거나, 휴대폰이 꺼지거나, PC에서 하다가 폰으로 옮겨도 그대로 이어서 해요.
- **계산은 서버가 해요.** (화면이 아니라 서버가 "알바하면 돈 +3000"을 정함)
  - 사용자가 브라우저에서 숫자를 조작해도 반영되지 않아요. 랭킹을 믿을 수 있어요.
- 저장되는 것
  | 무엇 | 내용 |
  |---|---|
  | 계정 | 닉네임, 암호화된 비밀번호, 가입일 |
  | 지금 인생 | 나이, 능력치, 돈, 직업, 위치, 꾸미기, 가방 |
  | **인생 기록** | 끝난 인생마다: 엔딩, 최종 능력치, 직업, 번 돈, 걸린 기간, 주요 사건 요약 |
  | 엔딩 도감 | 본 엔딩 목록 |
  | 행동 기록 | 최근 행동 내역 (문제 생겼을 때 되돌리기용) |
- **명예의 전당**: 이번 주 최고 부자, 최고 지능, 희귀 엔딩 달성자 등을 홈페이지에서 보여 줄 수 있어요.

## 6. 다른 유저 만나기와 대화

- 같은 마을에 접속한 사람들이 **실시간으로 지도에 보여요.** 걸어 다니는 모습까지 보여요.
- **한 마을(채널)에 최대 약 50명.** 사람이 많아지면 "마을 2", "마을 3"으로 자동으로 나눠요.
- 채팅
  - 말하면 **캐릭터 머리 위에 말풍선**이 뜨고, 아래 채팅창에도 기록돼요.
  - 채팅 종류: **근처 대화**(가까운 사람만) / **마을 전체**
  - 다른 캐릭터를 누르면 그 사람의 프로필이 보여요: 나이, 직업, 대표 엔딩
- 함께 하기 (2차 목표): 친구 추가, 카페에서 같이 쉬면 둘 다 행복 +, 선물 주기
- **안전장치 (팬 커뮤니티라 꼭 필요)**
  - 욕설·금칙어 자동 가리기
  - 같은 말 연속 도배 막기 (예: 2초에 1번만)
  - 신고 버튼 → 관리자(김치복)가 확인 후 채팅 금지 / 차단
  - 채팅 기록은 일정 기간만 보관

## 7. 기술 구조 (어떻게 만드나)

지금 홈페이지는 GitHub Pages(그림·글만 보여 주는 곳)라서, 로그인·저장·실시간 채팅을 하려면 **서버가 필요해요.**
이미 생방송 감지에 쓰고 있는 **Cloudflare**를 그대로 쓰면 돼요. **처음엔 무료 범위 안에서 충분해요.**

```
[휴대폰 / PC 브라우저]
   │  game.html (홈페이지에 올림)
   │
   ├─ 로그인·행동·저장 ──▶ Cloudflare Worker "kimchibok-game"
   │                         └▶ D1 데이터베이스 (계정, 인생, 기록 저장)
   │
   └─ 실시간 이동·채팅 ──▶ Cloudflare Durable Object (마을 하나 = 방 하나)
                             └▶ 같은 마을 사람들에게 위치·말풍선 전달
```

| 부분 | 쓰는 것 | 이유 |
|---|---|---|
| 게임 화면 | `game.html` + 그림 그리기(Canvas) | 휴대폰에서도 부드럽게 많은 캐릭터를 그림 |
| 캐릭터 그림 | SVG 부품 | 선명하고 가벼움, 꾸미기 쉬움 |
| 로그인·저장 | Cloudflare Worker + D1 | 이미 쓰는 Cloudflare, 무료 범위 넉넉 |
| 실시간 | Durable Objects + WebSocket | 같은 마을 사람끼리 즉시 주고받기 |

### 모바일 호환성 체크리스트
- 터치: 탭 = 이동, 끌기 = 지도 이동, 두 손가락 = 확대/축소
- 키보드가 올라와도 채팅창이 가려지지 않게
- 저사양 폰 배려: 화면 밖 캐릭터는 안 그림, 초당 30번만 그림
- 인터넷이 잠깐 끊겨도 자동 재접속, 마지막 저장 상태 유지
- 홈 화면에 추가하면 앱처럼 실행 (이미 사이트에 설정 있음)

## 8. 만드는 순서 (단계별)

| 단계 | 내용 | 끝나면 할 수 있는 것 |
|---|---|---|
| **0. 기획 확정** | 이 문서 다듬기, 화면 목업(그림) 만들기 | 어떤 게임인지 눈으로 확인 |
| **1. 혼자 하는 인생** | 로그인, 캐릭터 만들기, 지도 + 건물 6개, 행동·능력치, 매번 저장, 인생 결과 기록 | 혼자서 인생 한 판 끝까지 플레이 |
| **2. 함께하는 마을** | 다른 유저 보이기, 이동 동기화, 말풍선 채팅, 신고·차단 | 팬들끼리 만나서 대화 |
| **3. 재미 더하기** | 꾸미기 아이템, 랜덤 이벤트 확장, 엔딩 도감, 명예의 전당, 방송 연동 이벤트 | 계속 다시 하고 싶은 게임 |
| **4. 운영** | 관리자 화면, 밸런스 조정, 공지 | 오래 굴러가는 서비스 |

> 1단계 결과물만으로도 친구 몇 명에게 테스트를 부탁할 수 있어요.
