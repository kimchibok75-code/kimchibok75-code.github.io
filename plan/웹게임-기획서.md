# 웹 게임 기획서 — 치복 타운 (v0.4)

> 작성: 2026-11-15 · 상태: **기획 단계** (아직 만든 것 없음)
> v0.1의 "나이 먹고 인생 끝나는 게임", v0.2의 "역할(직업) 고르는 역할극"은 **모두 폐기**했어요.

## 1. 한 줄 소개

**이름: 「치복 타운」** (확정)
김치복 팬들이 **각자 머리 큰 SD 캐릭터를 만들어 들어와서 노는 마을**이에요.
정해진 목표나 역할 없이, 마을에서 **각자 하고 싶은 걸 하며 자기 캐릭터로 살아가요.** 수다, 낚시, 꾸미기, 산책, 구경… 뭐든지요.
나이를 먹거나 게임이 끝나는 일은 없어요. 내 캐릭터는 계속 그 마을에 살아요.

- 주소(예정): `https://kimchibok75-code.github.io/game.html`
- 홈페이지 메뉴와 휴대폰 하단 탭에 "치복 타운" 추가

### 이런 느낌이에요
- 퇴근하고 들어와서 광장에 앉아 다른 팬들이랑 수다 떨기
- 강가에서 낚시하다가 옆에 온 팬이랑 말 걸기
- 모은 코인으로 새 옷을 사서 캐릭터 꾸미기, 내 집 꾸며서 친구 초대하기
- 김치복 방송 시간에는 광장에 다 같이 모여서 이벤트 즐기기

## 2. 핵심 재미

### 2-1. 내 캐릭터 = 마을 속 나
- 처음 들어오면 **SD 캐릭터를 만들어요.** 얼굴, 머리 모양, 옷, 색깔을 골라요.
- 캐릭터 정보: 닉네임, **칭호**(예: "카페 단골", "낚시왕", "림월드 고인물"), 한 줄 자기소개, 지금 기분(상태 표시)
- 내 캐릭터는 **계속 유지돼요.** 다음에 들어오면 마지막 장소, 마지막 옷 그대로 다시 시작해요.

### 2-2. 하고 싶은 거 하기 — 정해진 것 없음
- **목표, 퀘스트, 역할, 직업 없음.** 들어와서 마음 가는 대로 놀아요.
- 마을 곳곳에 **누구나 할 수 있는 놀거리**를 깔아 두는 방식이에요.

| 놀거리 | 어디서 | 내용 |
|---|---|---|
| 💬 수다 떨기 | 어디서나 | 말풍선 채팅, 이모트 |
| 🪑 앉아서 쉬기 | 광장 벤치, 카페 의자 | 옆자리에 다른 팬이 앉으면 나란히 앉음 |
| 🎣 낚시 | 강가 | 물고기 잡기 → 도감 수집, 코인 조금 |
| 🌾 텃밭 | 텃밭 | 씨 심고 시간 지나면 수확 |
| 🌲 탐험 | 개척지 | 돌아다니다 재료 줍기, 가끔 랜덤 사건 (림월드 느낌 문장) |
| 👕 꾸미기 | 옷가게, 미용실 | 옷·머리 바꾸기 |
| 🏠 집 꾸미기 | 내 집 | 가구 배치, 친구 초대 |
| 🎁 주고받기 | 어디서나 | 선물, 음료 건네주기 |
| 🛒 구경·교환 | 시장 | 유저끼리 아이템 교환 |
| 📸 사진 | 어디서나 | 친구들이랑 모여서 기념 사진 |

### 2-3. 마을 지도와 건물
**바깥 지도(마을)** 안에 건물이 있고, 건물을 누르면 **건물 안 지도**로 들어가요. 건물 안에서도 다른 유저를 만나요.

| 장소 | 하는 일 |
|---|---|
| ⛲ 광장 | 마을 중심, 제일 많이 모이는 곳. 앉을 벤치, 전광판 |
| ☕ 카페 | 앉아서 대화, 음료 마시기 |
| 🏠 내 집 | **각자 하나씩.** 가구 배치해서 꾸미기, 친구 초대 |
| 👕 옷가게 / 💇 미용실 | 옷·머리 바꾸기, 코인으로 아이템 구입 |
| 🛒 시장 | 구경, 유저끼리 아이템 교환 |
| 📺 방송국 | 김치복 테마 장소. 방송 중일 때 다 같이 모이는 곳 |
| 🎣 강가 / 🌾 텃밭 | 낚시·농사 같은 가벼운 놀거리 |
| 🌲 개척지 (마을 밖) | 탐험, 재료 모으기, 가끔 랜덤 사건 (림월드 느낌의 문장) |
| 🎡 놀이터 (나중에) | 여럿이 하는 미니게임 |

> 림월드 느낌은 **분위기와 사건 문장**으로만 살려요. 림월드 게임 그림이나 이름은 쓰지 않아요(저작권).

### 2-4. 코인과 아이템 (가볍게)
- **코인**은 매일 접속, 낚시·텃밭, 이벤트 참여로 조금씩 모여요.
- 코인으로 **옷, 머리, 모자, 가구, 이모트**를 사요. → 꾸미기 = 나를 표현하는 재미
- 돈 버는 게 목적이 되지 않게, 숫자는 작고 단순하게 유지해요.

### 2-5. 소통 — 이 게임의 중심
- **말풍선 채팅**: 말하면 내 캐릭터 머리 위에 뜨고, 아래 채팅창에도 남아요.
  - **근처 대화**(같은 장소, 가까운 사람) / **마을 전체** / **귓속말**(1:1)
- **감정 표현(이모트)**: 손 흔들기, 박수, 하트, 웃음, 춤, 앉기
- **같이 하기**: 같은 벤치에 나란히 앉기, 음료 건네주기, 선물 주기, 사진 찍기(화면 캡처)
- **친구**: 친구 추가하면 친구가 어디 있는지 보이고 바로 찾아갈 수 있어요.
- 다른 캐릭터를 누르면 **프로필 카드**가 떠요: 닉네임, 칭호, 자기소개, 지금 기분

### 2-6. 김치복과 연결 (홈페이지만의 특별함)
- **김치복이 치지직 방송 중이면 마을 광장 전광판이 켜지고 이벤트가 열려요.**
  - 그 시간 접속하면 특별 코인, 한정 칭호 등
  - 이미 만들어 둔 생방송 감지(Cloudflare Worker)를 그대로 활용
- 김치복 본인이 들어오면 **특별한 표시(왕관 등)**가 붙는 관리자 캐릭터
- 팬 카페 새 글이 올라오면 광장 게시판에 제목 표시 (나중에)

## 4. SD 캐릭터 (확정: Claude가 직접 그림)

- **아주 단순한 모양으로 시작해요.**
  - 얼굴: **둥근 사각형**, 얼굴에는 **눈만 두 개** (입·코 없음)
  - 몸: 둥근 사각형, 팔·다리: 짧은 둥근 막대
  - 머리가 몸보다 크게 (머리 : 몸 ≈ 1.2 : 1)
- 꾸미기는 처음엔 **색깔 바꾸기**(얼굴색, 옷 색)로 시작 → 나중에 모자·머리카락 부품 추가
- 눈 모양으로 감정 표현: 기본 ● ●, 웃음 ^ ^, 놀람 ○ ○, 졸림 − −
- 움직임: 걸을 때 통통 튀기 + 팔다리 흔들기, 앉기, 이모트
- 그림은 코드로 그려요 (그림 파일 없이) → 가볍고 휴대폰에서도 선명

## 4-1. 지도 모양 (확정)
- **위에서 비스듬히 내려다보는 시점** — 건물의 **지붕(윗면)과 앞벽(앞면)이 같이 보이는** 2D 타일 지도
  - 옛날 휴대용 게임기 RPG에서 많이 쓰던 시점. 시점만 참고하고, 다른 게임의 그림이나 캐릭터는 쓰지 않아요.
- 바닥은 네모 칸(타일): 풀, 길, 물, 모래
- 캐릭터가 건물·나무 **뒤로 가면 가려지고, 앞으로 오면 앞에 보여요** (아래쪽에 있는 것이 앞에 그려짐)

## 5. 로그인과 저장

### 5-1. 로그인 (확정: 닉네임 + 비밀번호, 이메일 없음)

**닉네임 규칙**
- 2~10글자, 한글·영문·숫자만 (띄어쓰기·특수문자 안 됨)
- 다른 사람과 겹치면 안 됨 (대소문자 구분 없이)
- 금지어가 들어간 닉네임 안 됨, "김치복·치복·관리자·운영자·admin" 같은 사칭 단어 안 됨
- 닉네임 변경: 30일에 한 번

**비밀번호 규칙**
- 8~64글자, **영문과 숫자를 둘 다** 넣어야 함 (특수문자는 넣어도 되고 안 넣어도 됨)
- 닉네임과 같거나 닉네임이 들어간 비밀번호 안 됨
- 너무 흔한 비밀번호 안 됨 (예: `password1`, `qwer1234`, `abc12345` 같은 목록)
- 같은 글자만 반복하는 것 안 됨 (예: `aaaa1111`)
- 서버에는 비밀번호를 그대로 저장하지 않고 **암호화(해시)**해서 보관
- 로그인 **5번 틀리면 10분 동안** 그 닉네임으로 로그인 막힘 (남이 비밀번호 맞히기 방지)
- "로그인 유지" 체크 시 30일 동안 자동 로그인

**비밀번호 찾기 — 이메일 없이 하는 방법 2가지**
1. **복구 코드 (기본)**
   - 가입이 끝나면 **복구 코드 12자리**를 한 번 보여 줘요. 예: `K7QM-2XPA-9RTD`
   - "복사하기", "이미지로 저장하기" 버튼 제공. "저장했어요" 체크해야 다음으로 넘어감
   - 비밀번호를 잊으면: 로그인 화면 → "비밀번호를 잊었어요" → 닉네임 + 복구 코드 + 새 비밀번호 입력
   - 한 번 쓴 복구 코드는 사라지고 **새 복구 코드**를 다시 보여 줘요.
   - 설정 화면에서 언제든 복구 코드 새로 발급 가능 (지금 비밀번호 입력 필요)
2. **관리자에게 요청 (복구 코드도 잃어버렸을 때)**
   - 김치복 디스코드나 팬 카페로 문의 → 김치복님이 관리자 화면에서 **임시 비밀번호** 발급
   - 본인 확인 질문: 캐릭터 색깔, 친구 닉네임, 마지막 접속 날짜 등 (관리자 화면에 표시됨)
   - 임시 비밀번호로 로그인하면 **바로 새 비밀번호를 정하게** 함
- 나중에 추가 가능: 디스코드 계정 연결 → 디스코드로도 로그인·복구

### 5-2. 저장 — "매번 잘 저장"
- **무언가 바뀔 때마다 서버에 바로 저장**해요. 저장 버튼이 따로 없어요.
  - 창을 닫거나 휴대폰이 꺼져도, PC에서 하다가 폰으로 옮겨도 그대로 이어져요.
- **중요한 계산은 서버가 해요.** 코인이나 아이템을 화면에서 조작해도 반영되지 않아요.

| 저장되는 것 | 내용 |
|---|---|
| 계정 | 닉네임, 암호화된 비밀번호, 가입일 |
| 캐릭터 | 생김새(부품), 입은 옷, 칭호, 자기소개, 기분 |
| 위치 | 마지막으로 있던 장소와 좌표 |
| 가방 | 코인, 가진 아이템 |
| 내 집 | 가구 종류와 배치 |
| 친구 | 친구 목록, 차단 목록 |
| 기록 | 물고기 도감, 받은 칭호, 참여한 이벤트, 최근 활동 내역 (문제 생겼을 때 되돌리기용) |

## 6. 다른 유저와 함께 — 실시간

- 같은 장소에 있는 사람들이 **실시간으로 보이고 걸어 다녀요.**
- **한 마을(채널)에 최대 약 50명.** 넘으면 "마을 2", "마을 3"으로 자동으로 나눠요. 친구가 있는 마을로 이동도 가능
- 건물 안, 내 집도 각각 하나의 방이라서 그 안에 있는 사람끼리 보여요.
- 개인 차단: 차단한 사람의 말과 캐릭터가 나에게 안 보임
- 내 집은 **잠금 / 친구만 / 모두** 중에 골라서 공개

## 6-1. 채팅 규칙 (확정 초안)

| 규칙 | 내용 |
|---|---|
| **최대 글자 수** | 한 번에 **60글자**까지 (말풍선이 화면을 덮지 않게). 입력창에 `23/60` 표시 |
| **보내는 속도** | **1초에 1번**까지. 더 빨리 보내면 "천천히 말해 주세요" |
| **도배 막기** | 10초 안에 5번 넘게 보내면 **30초 동안 채팅 쉬기** |
| **같은 말 반복** | 똑같은 말을 **3번 연속** 보내면 안 보내짐 |
| **글자 반복 줄이기** | `ㅋㅋㅋㅋㅋㅋㅋㅋㅋㅋㅋㅋ`처럼 같은 글자가 10번 넘게 이어지면 **10개로 자동으로 줄임** |
| **금지어** | 욕설·비하·성적인 말은 `***`로 가림. 띄어쓰기나 특수문자를 섞어서 피해 가는 것도 잡음 (예: `시.발`, `ㅅ ㅂ`) |
| **아주 심한 말** | 아예 안 보내지고 **경고 1회** |
| **개인정보 보호** | 전화번호·이메일·주민번호처럼 보이는 글은 자동으로 가림 (본인 보호) |
| **링크 금지** | 인터넷 주소는 안 보내짐 (광고·사기 방지). 김치복 공식 링크(유튜브·치지직·카페·디스코드)만 허용 |
| **새 계정** | 가입 후 **10분 동안**은 근처 대화만 가능, 마을 전체 채팅 불가 (도배용 계정 방지) |
| **말풍선** | 머리 위에 **5초** 보였다가 사라짐. 채팅창에는 남음 |

**경고와 자동 제재**
- 경고 3번 → **10분 채팅 금지** → 또 3번 → **1시간** → 또 3번 → **24시간**
- 경고는 7일 지나면 하나씩 사라짐
- 영구 차단은 **김치복님이 직접** 결정 (자동으로는 안 함)

**신고 (처리: 김치복님)**
- 캐릭터 누르기 → 프로필 카드 → "신고" → 이유 고르기 (욕설 / 도배 / 불쾌한 행동 / 사칭 / 기타)
- 신고하면 **그 사람의 최근 채팅 20줄이 자동으로 첨부**돼서 김치복님이 상황을 볼 수 있음
- 서로 다른 3명 이상이 신고하면 김치복님 확인 전까지 **임시로 근처 대화만** 가능
- 관리자 화면: 신고함, 채팅 기록 검색, 채팅 금지(시간 선택), 내보내기, 영구 차단, 공지 띄우기
- 관리자 채팅 명령어도 제공: `/공지 내용`, `/조용 닉네임 10분`, `/내보내기 닉네임`

**보관**
- 채팅 기록은 **30일** 보관 후 자동 삭제 (신고된 대화는 처리 끝날 때까지 보관)

## 7. 기술 구조 (어떻게 만드나)

지금 홈페이지는 GitHub Pages(그림·글만 보여 주는 곳)라서, 로그인·저장·실시간 채팅을 하려면 **서버가 필요해요.**
이미 생방송 감지에 쓰고 있는 **Cloudflare**를 그대로 쓰면 돼요. **처음엔 무료 범위 안에서 충분해요.**

```
[휴대폰 / PC 브라우저]
   │  game.html (홈페이지에 올림)
   │
   ├─ 로그인·꾸미기·아이템·저장 ──▶ Cloudflare Worker "kimchibok-game"
   │                                 └▶ D1 데이터베이스 (계정, 캐릭터, 가방, 집, 친구)
   │
   └─ 실시간 이동·채팅·이모트 ──▶ Cloudflare Durable Object (장소 하나 = 방 하나)
                                     └▶ 같은 방 사람들에게 위치·말풍선 전달
```

| 부분 | 쓰는 것 | 이유 |
|---|---|---|
| 게임 화면 | `game.html` + Canvas(그림 그리기) | 휴대폰에서도 캐릭터 여러 명을 부드럽게 |
| 캐릭터 그림 | SVG 부품 | 선명하고 가벼움, 꾸미기 쉬움 |
| 로그인·저장 | Cloudflare Worker + D1 | 이미 쓰는 Cloudflare, 무료 범위 넉넉 |
| 실시간 | Durable Objects + WebSocket | 같은 장소 사람끼리 즉시 주고받기 |

### 모바일 호환성 체크리스트
- 터치: 탭 = 이동, 끌기 = 지도 이동, 두 손가락 = 확대/축소
- 키보드가 올라와도 채팅창이 가려지지 않게
- 저사양 폰 배려: 화면 밖 캐릭터는 안 그림, 초당 30번만 그림, 이동은 꼭 필요한 정보만 주고받기
- 인터넷이 잠깐 끊겨도 자동 재접속, 마지막 상태 그대로
- 홈 화면에 추가하면 앱처럼 실행 (사이트에 이미 설정 있음)
