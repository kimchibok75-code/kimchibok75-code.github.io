# 치복 타운 밸런스 검토 (2026-11-20)

> 실제 게임 규칙 파일(game-rules.js)과 서버 사냥 계산(hunt.js)을 그대로 돌려서 잰 값입니다. 게임 파일은 하나도 안 바꿨습니다.
> 시험 계산 스크립트: 임시 폴더 `scratchpad\bal-growth`, `bal-gear`, `bal-life`, `bal-reward`

## 기준: 사냥 1시간 (55레벨까지 평범하게 큰 캐릭터, 물약 있음)

| 레벨 / 사냥터 | 골드/시간 | 경험치/시간 |
|---|---|---|
| 10 숲 | 1.1~2.1만 | 5~8만 |
| 20 숲 | 3.8~4.2만 | 16~18만 |
| 30 협곡 | 7.1~7.5만 | 34~36만 |
| 40 공장 | 11.6만 | 56~58만 |
| 55 공장 / 폐광 / 늪지 | 14~17만 / 16~18만 / 19~20만 | (55는 경험치 의미 없음) |

- 1→55: 검사 16.1시간 · 궁수 14.7시간 · 마법사 15.4시간. 레벨 구간마다 고르게 늘어나서 **튀는 구간 없음** (좋음)
- 장비가 레벨업 속도에 주는 차이는 10% 정도 (몬스터 사이를 걷는 시간이 한계)

## 🔴 심각 (오픈 전에 꼭 고칠 것)

### 1. 전설 물고기·전설 작물 값이 다른 모든 수입을 압도함
- 낚시 L10(낚싯대=미끼 10단계): **시간당 약 94만 골드** = 55레벨 사냥의 5~6배. 수입의 90%가 전설 물고기(강의 용 500만, 수정 리바이어던 1,000만)
- 텃밭 L10: **시간당 약 52만**, 하루 상한 없음, 낚시·알바와 **동시에** 돌아감
- L7→L8에서 수입이 2.5~3배로 갑자기 뜀 (전설이 풀리는 단계)
- 이게 열리면 가챠·강화·스킨·집 등 골드 쓰는 곳이 전부 의미를 잃음
- 고칠 방법: 전설 값에 ×0.2 배율 (L10 낚시 ≈ 25만, 텃밭 ≈ 15만), 최고 값 1,000만 → 100만, 텃밭도 하루 수확 상한(넘으면 값 절반), 낚시 하루 400마리 → 250마리
- ⚠️ 물고기·작물 값은 김치복님 엑셀 기획에서 온 숫자라 **바꿀지 직접 정해 주세요**

### 2. 운(행운) 몰빵 + 프리셋 무료 교체 = 골드 2~3배
- 운 1 = 골드 +1%, 상한 없음. 55레벨 운 몰빵이면 골드 약 2.1배 (늪지 19만 → 40만)
- 프리셋은 공짜로 언제든 바꿈 → **보상 받기 직전에 운 프리셋으로 바꾸면** 레이드 보상·자리 비움 보상이 약 3.2배, 강화 확률도 +12%p (+19 강화 5% → 17%)
- 고칠 방법: 운의 골드 효과를 `운 × 0.3`, 최대 +50%로 / 강화 확률은 더하기 대신 곱하기 / 프리셋 바꾸기에 10분 쿨타임

### 3. 스킨 보유 효과가 끝없이 쌓임 (공격력 최대 +303%)
- 무기 스킨 효과가 **안 쓰는 무기에도** 붙음 (왕 세트 3개 × 무기 3개 = 공격력 +36%)
- 레이드 스킨 레벨: Lv10이면 효과 5.5배 → 레이드 스킨만으로 공격력 +209%
- 비교: 장비를 신화로 바꿔도 +18%, +20 강화도 +37%. **스킨이 장비보다 10배 강함**
- 고칠 방법: 무기 스킨은 지금 클래스 무기만 셈 / 레이드 스킨 레벨당 +50% → +15% / 공격력·체력 % 합계 상한 100%

### 4. 레이드 골드가 큼
- 레이드 1번(3~4분)이 사냥 골드 수십 분어치 → 30분마다 안 가면 손해인 구조
- 21명 이상이면 +60% 인원 보너스까지
- 고칠 방법: 레이드 골드 배수 0.4 → 0.15쯤, 인원 보너스 최대 +60% → +30%

## 🟡 중간

### 5. 초반 경험치가 너무 많음
- 가이드 퀘스트 경험치만으로 Lv1 → **Lv13**, 쉬운 3단계(걷기·건물 누르기·임무 받기)만 해도 Lv5
- 주민 임무 1개로 Lv1→3, 4시간 자리 비움 한 번으로 Lv1→8
- 원인: 보상 경험치 공식에 고정 +10,000이 들어 있음 (`npcExp`, 자리 비움)
- 고칠 방법: 보상 경험치를 '그 레벨 필요 경험치의 30%'까지로 제한

### 6. 카페 알바 레벨 30이 레벨 낮은 사냥보다 3~4배 벎
- 알바 레벨 30 = 1분 1,030골드 = 시간당 5.7만 (캐릭터 레벨과 상관없음, 약 5시간이면 도달)
- 고칠 방법: 알바비 `80 + 레벨×14` → `80 + 레벨×8`, 팁 `8 + 레벨×2.2` → `8 + 레벨×1.2` (최대 약 3.5만/시간)

### 7. 방송 보너스 경험치·골드 +100%
- 방송 3시간 = 사냥 3시간어치를 공짜로 더 받음. 다른 효과와 더해짐
- 고칠 방법: +50%로 (의도한 큰 보상이면 그대로 둬도 됨)

### 8. 자리 비움을 4시간마다 반복해서 받을 수 있음
- 4시간마다 잠깐 접속하면 하루 6번 → 골드 4~6시간어치가 플레이 없이 생김
- 고칠 방법: 하루 합계 8시간 상한

### 9. 효과 합계가 큼 (최악의 경우)
- 경험치 +315% (4.2배), 골드 +548% (6.5배, 운 포함). 칭호 골드 합 +50%가 특히 큼
- 고칠 방법: 경험치 보너스 최대 +150%, 골드 보너스(운 제외) 최대 +200%

### 10. 검사가 높은 레벨에서 뒤처짐
- 55레벨 공장 경험치: 검사 69만 / 마법사 78만(+12%) / 궁수 81만(+18%). 장비 최고면 궁수 +31%
- 원인: 원거리가 덜 걸어도 됨 + 민첩이 이동 속도도 올림
- 고칠 방법: `FAR_WALK` 0.8 → 1.0, `MELEE_K` 2.6 → 2.9 (차이 10% 안으로)

### 11. 전설 스킬이 보통 스킬보다 약함
- 초당 피해: 보통 돌진 베기·연속 사격·불덩이 .35~.40 vs 전설 대지 가르기·관통 화살·화살비·메테오 .18~.24
- 전투 함성(+9%)·매의 눈(+6%)도 약함
- 고칠 방법: `s_quake` 3.2→6, `b_pierce` 3.6→6, `b_rain` .9→1.5, `m_meteor` 6→11, `m_ice` 1.6→2.4, 전투 함성 30→50, 매의 눈 35→50

### 12. 사냥터 보스가 위험 없이 골드의 30~48%
- 서버가 '이길 수 있을 때만' 보스와 싸워서 보스에게 죽는 일이 없음
- 고칠 방법: 보스 골드 30% 줄이기 (공장 1만→7천, 폐광 1.4만→1만, 늪지 2만→1.4만) 또는 보스 5분 → 7.5분

### 13. 폐광·늪지가 55레벨에게 쉬움, 폐광은 늪지에 밀려 갈 이유가 없음
- 장비가 낮아도 물약만 있으면 둘 다 안 죽고 보스도 다 잡음
- 55레벨에서 늪지는 공장 +32%, 폐광은 +12% → 늘 늪지
- 고칠 방법: 폐광 몬스터 골드 ×1.25, 늪지 몬스터 공격력 +25%

### 14. 방어구 '사냥 중 회복' 옵션이 3칸에 쌓임
- 전설 방어구 3칸이면 회복이 기본의 3배 → 물약을 거의 안 씀
- 고칠 방법: 옵션 값 절반 또는 회복 합계 상한

### 15. 궁전 임대료 시간당 4.5만 (가만히 있어도)
- 1번(낚시·텃밭)을 고치면 그대로 둬도 됨. 아니면 임대료를 1/2~1/3로

### 16. 사냥 골드만으로는 장비 맞추기가 빠듯함
- 1→55까지 사냥으로 버는 돈 약 92만 / 가챠 7레벨 약 73만, 6칸 +10 강화 약 156만
- 1번을 고치면 사냥만 하는 사람은 장비가 늦어짐 → 몬스터 골드 +25% 또는 중간 가챠·강화 값 조금 내리기를 같이 보기
